Le réseau,
c'est en option.

Vos données vivent dans une base SQLite chiffrée AES-256 sur votre téléphone. La synchronisation cloud Supabase est optionnelle, activable en un clic, et désactivable à tout moment.

  • Aucune connexion requise
    Saisie, recherche, statistiques, rapports PDF — tout fonctionne hors-ligne, instantanément.
  • Synchronisation en arrière-plan
    Quand le réseau revient, la file de sync pousse uniquement les changements. Stratégie last-write-wins.
  • Plusieurs téléphones, un seul élevage
    Compte Supabase partagé entre admin et soigneurs, rôles distincts, RLS Postgres côté serveur.
  • Sauvegarde locale chiffrée
    Export .cunigest AES-256-GCM, partageable par WhatsApp, mail ou clé USB.
