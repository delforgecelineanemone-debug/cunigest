🐇 CuniGest

Politique de confidentialité & protection des données

📋 En résumé

CuniGest est une application de gestion d'élevage cunicole. Vos données ne quittent jamais votre téléphone sauf si vous activez explicitement la synchronisation cloud.

🔒 Données collectées

  • Données d'élevage (lapins, saillies, soins, ventes, etc.) — stockées localement sur votre appareil, chiffrées avec AES-256.
  • Aucune donnée personnelle n'est collectée automatiquement (pas de nom, email, localisation, publicité, tracking).
  • Rapports d'erreurs anonymes (via Sentry) — envoyés uniquement en cas de crash, sans données d'élevage. Vous pouvez désactiver cela en coupant la connexion internet.

☁️ Synchronisation cloud (optionnelle)

La synchronisation vers Supabase est désactivée par défaut. Si vous l'activez :

  • Vos données sont transmises chiffrées via TLS (HTTPS).
  • Elles sont stockées dans votre espace cloud personnel, protégé par vos propres identifiants.
  • Vous pouvez désactiver la sync et supprimer vos données cloud à tout moment depuis les réglages de l'app.

📦 Sauvegardes

  • Les sauvegardes locales (format .cunigest) sont chiffrées par votre mot de passe (AES-256-GCM / PBKDF2).
  • Elles ne sont partagées qu'à votre initiative (bouton "Sauvegarder & partager").

📋 Vos droits (RGPD)

  • Accès — toutes vos données sont visibles directement dans l'app.
  • Suppression — désinstallez l'app ou effacez ses données dans les paramètres Android.
  • Portabilité — utilisez la fonction d'export pour récupérer vos données.
  • Rectification — modifiez directement depuis l'interface.

🛡️ Sécurité

  • Base de données locale chiffrée avec SQLCipher (AES-256).
  • Clé de chiffrement stockée dans le Keystore sécurisé Android.
  • Mots de passe hashés avec PBKDF2-HMAC-SHA256 (100 000 itérations, sel aléatoire par compte).

👤 Publicités et tiers

CuniGest ne contient aucune publicité et ne partage aucune donnée avec des tiers à des fins commerciales. Aucun SDK de tracking (Firebase Analytics, Facebook, etc.) n'est intégré.
